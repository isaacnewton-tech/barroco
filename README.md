# **Barroco - Página Interativa**

Este projeto foi desenvolvido com HTML, CSS e JavaScript para apresentar de forma interativa e didática as principais características do estilo artístico Barroco.

🎨 Sobre o Projeto
O site tem como objetivo explicar o contexto histórico, os principais autores e obras do Barroco, utilizando uma interface moderna e responsiva.

🚀 Tecnologias Utilizadas
- **HTML5**: Estruturação da página.
- **CSS3**: Estilização e responsividade.
- **JavaScript**: Interatividade e dinamismo na página.

📜 Funcionalidades
- **Contexto Histórico**: Explicação sobre a origem e evolução do Barroco.
- **Principais Autores**: Informações sobre grandes nomes como Gregório de Matos e Bento Teixeira.
- **Principais Obras**: Análise de obras icônicas como "A Anunciação" de Caravaggio e "A Ronda Noturna" de Rembrandt.
- **Vídeos Explicativos**: Seção com vídeos educativos para aprofundamento no tema.
